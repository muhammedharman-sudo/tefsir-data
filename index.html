🔑 GitHub Token Ayarla
Tefsir düzenlemelerinizin GitHub'a otomatik kaydedilmesi için bir Personal Access Token gerekir.

Nasıl alınır:
1. GitHub → Settings → Developer settings
2. Personal access tokens → Tokens (classic)
3. Generate new token → sadece repo yetkisini işaretle
4. Oluşan kodu buraya yapıştır

Bu token sadece bu telefonda saklanır, kimseyle paylaşılmaz.
🕋 Arapça Kaynakları
Sure numarası ve GitHub raw URL'sini girin. Format: her Arapça satırın altında tek başına "N." şeklinde numara satırı olmalı. Yüklenince bu sürenin tüm ayetlerindeki Arapça metin, mevcut API yerine bu metinle gösterilir.
🖋️ Meal Kaynakları
Mütercim adı, sure numarası ve GitHub raw URL'sini girin. Bu meal, ilgili ayetin Çeviriler ekranında diğer meallerle birlikte, dipnotlarıyla gösterilecek. Salt-okunurdur, düzenlenemez.
📖 Tefsir Kaynakları
GitHub'daki tefsir dosyasının raw URL'sini girin. Sayfa her açıldığında otomatik çeker ve ilgili ayetlere "Tefsir" notu olarak ekler.
